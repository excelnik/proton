# Pruton 0.4.3-beta.5

## ביצועים
- הוגבל מספר השורות שנבנות ומוצגות במסך סיווג תנועות ל-200 בכל פעם, עם אפשרות להציג עוד.
- חישובי סינון ומיון במסך התנועות נשמרים בין רינדורים ואינם רצים מחדש בכל שינוי מצב שאינו קשור לנתונים.
- יצירת תחזיות וירטואליות מדולגת בתצוגת כל הזמנים ובתצוגת שנה, שבהן התחזיות אינן מוצגות.
- פעולות שינוי ומחיקה מרובות במסך התנועות מבוצעות בעסקת SQLite אחת.
- נוספו אינדקסים למסד הנתונים כדי לזרז טעינת תנועות, איתור תנועות חשודות, תחזיות וכללי סיווג.

## סיווג אוטומטי
- הוחזרה הלמידה האוטומטית מהגרסה המקורית: סיווג ידני שומר או מעדכן כלל אוטומטי ללא חלונית אישור.
- התנועה שסווגה נשארת מוצגת ברשימת הסיווג, כמו בגרסה המקורית.

## תאימות נתונים
- האינדקסים נוצרים באמצעות migration בטוח ואידמפוטנטי, ללא שינוי או מחיקה של נתוני המשתמש.
